To use these files...
1) Make a project in your 288 workspace
2) Move all these files into the workspace

When done...
1) Click the "Add file" drop down
2) Click "Upload files"
3) Drag and drop the main.c file, the final_project folder, and the lab folder
4) Enter a descriptive commit title and message
5) For this project, make sure the "Commit directly to the main branch"  is selected.
6) Click "Commit changes" to finish uploading the files
